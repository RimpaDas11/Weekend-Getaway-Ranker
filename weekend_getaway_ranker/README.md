
# Weekend Getaway Ranker (Data Engineering Project)

## Problem Statement
Build a recommendation engine that ranks top weekend destinations from a given source city based on distance, rating, and popularity.

## Tech Stack
- Python
- Pandas

## Features
- Distance calculation using Haversine formula
- Weighted scoring system
- Supports multiple source cities
- Easily extendable dataset

## Installation & Execution
```bash
git clone <repo_url>
cd weekend_getaway_ranker
pip install -r requirements.txt
python weekend_getaway_ranker.py
```
